# Répertoire Scratch & Bancs d'Essais Éphémères

Ce répertoire est exclusivement réservé aux scripts temporaires, bancs d'essais d'exécution et diagnostics en lecture de l'Agent IA (**AImi**).

- Les fichiers créés ici ne doivent jamais faire partie du livrable de production.
- Les tests éphémères exécutés ici ne modifient en rien le code source applicatif du projet hôte.
